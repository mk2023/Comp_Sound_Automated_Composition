Using Pitch Set Theory for Automated Composition

Enter an ordered pitch-class sequence (0–11), assumed already in normal form.

Possible Operations:
Tn (transpose by n semitones mod 12),
I (inversion about 0: x ↦ −x mod 12),
R (retrograde, which reverses order of the sequence)

Then, the piece will go randomly go through the operations and concatenate the resulting sequences to form a musical piece.

Example: 0, 2, 4, 5

Do you want me to play only the final output (after N operations), or build a whole composition using each mid-step as well?
